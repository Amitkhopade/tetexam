# Combined Project Package — Not a Patch

This directory is the complete `question-paper-platform` project distribution. Extract the ZIP to a folder, install frontend dependencies, and run `npm run dev`. It includes the original source data, runtime datasets, Python processor, login/timed-exam UI, Admin AI generator, manual JSON uploader, tests, and documentation. Do not extract this ZIP over an unrelated repository without first backing up local changes.

See `README.md` and `docs/RELEASE_MANIFEST.md` for contents, local run instructions, test status, and limitations.
